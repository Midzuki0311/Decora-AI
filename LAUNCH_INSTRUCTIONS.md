## 7️⃣ Решение проблем

### Проблема: Не загружается история
```
Решение:
1. Проверьте авторизацию (token в headers)
2. Убедитесь, что backend работает
3. Откройте Network tab для поиска ошибки 401/403
4. Проверьте логи backend
```

### Проблема: Лайки не сохраняются
```
Решение:
1. Проверьте что toggleLike API работает
2. Убедитесь что история обновляется после лайка
3. Проверьте статус-код 200 в Network
4. Очистите AsyncStorage: AsyncStorage.removeItem('designHistory')
```

### Проблема: AsyncStorage не определен
```
Решение:
1. Установите пакет: npm install @react-native-async-storage/async-storage
2. Пересоберите проект: npx expo prebuild --clean
3. Очистите node_modules: rm -rf node_modules && npm install
```

### Проблема: История не сохраняется при перезапуске
```
Решение:
1. Убедитесь что AsyncStorage установлен
2. Проверьте что saveGenerationToHistory() вызывается
3. Проверьте ошибки в консоли при сохранении
4. Попробуйте вручную: AsyncStorage.setItem('designHistory', data)
```
